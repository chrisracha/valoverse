# ValoVerse

A Valorant agent database and management system. Users can browse agents, and registered users can add and manage their own agent submissions.

## Features

*   View Valorant agents and their stats.
*   User registration and login.
*   CRUD functionality for agents (for logged-in users).

## Technologies Used

*   PHP
*   MySQL
*   HTML/CSS
*   JavaScript/jQuery

## Setup

1.  Import the `project_beta1.sql` file into your MySQL database.
2.  Update the database credentials in `php/account_dashboard.php` and other PHP files as needed.
3.  Place the project files in your web server's root directory.
4.  Open the `index.php` file in your browser.
